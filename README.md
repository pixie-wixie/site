# Pixie Wixie

Статичний українськомовний блог. Без бекенда, npm, залежностей і етапу збірки.

## Перегляд

Відкрийте `index.html` у браузері. Усі сторінки й переходи працюють без JavaScript.

За бажанням локальний сервер: `python3 -m http.server 8000`, далі http://localhost:8000.

## Публікація

Завантажте кореневі HTML-файли, `style.css`, `robots.txt`, `sitemap.xml` та папки `articles/` і `img/` на статичний хостинг зі збереженням структури. Відносні посилання підтримують розміщення в піддиректорії. Налаштування маршрутизації не потрібне.

Зображення завантажуються з Unsplash, шрифт — із Google Fonts; для них потрібен інтернет. Якщо шрифт недоступний, використовується системний. Власного сервера або API сайт не потребує.

## Редагування

Редагуйте тексти безпосередньо в HTML. Усі HTML-файли статей зберігайте в `articles/`. Щоб додати статтю, скопіюйте файл у цій папці, оновіть текст, унікальні метадані й JSON-LD, а потім за потреби додайте посилання `articles/назва.html` на сторінку `materials.html`. Із файлів статей використовуйте `../style.css`, `../img/` та `../materials.html`. Після додавання статті запустіть `python3 scripts/set_site_url.py https://pixiewixie.com`, щоб оновити SEO-адреси та sitemap. Оформлення спільне у `style.css`.

## SEO

Кожна сторінка має унікальні title і description, українську мову, Open Graph, Twitter Card та JSON-LD (WebPage, CollectionPage, AboutPage або BlogPosting). Контент і навігація доступні без JavaScript. `robots.txt` дозволяє сканування.

Після визначення публічної HTTPS-адреси виконайте одноразово:

```sh
python3 scripts/set_site_url.py https://ВАШ-ДОМЕН
```

Команда записує абсолютні canonical та og:url, доповнює JSON-LD, створює `sitemap.xml` і вказує його у `robots.txt`. Це підготовка файлів перед публікацією; сайт залишається статичним. Не запускайте з вигаданим доменом для публічної версії. Для хостингу в піддиректорії robots.txt потрібно також розмістити в корені домену.

Після публікації перевірте доступність сторінок і sitemap через HTTPS, додайте сайт у Google Search Console та надішліть sitemap. Дати публікації слід узгодити з фактичним виходом статей. Не додавайте фіктивні рейтинги, авторів чи дати оновлення. Метадані та структурована розмітка не гарантують позицій або спеціального вигляду в пошуку.

## Список статей і сторінки каталогу

Каталог показує статті вертикально, по 10 на сторінку. Після додавання HTML-статті в `articles/` задайте порядковий номер у `<article data-article-order="2">`, додайте її JSON-LD типу `BlogPosting` і обкладинку `<img class="article-cover" ...>`.

Оновлення каталогу й SEO-файлів перед публікацією:

```sh
python3 scripts/build_materials.py
python3 scripts/set_site_url.py https://pixiewixie.com
```

Генератор створює `materials.html`, а за потреби `materials-2.html`, `materials-3.html` тощо. Кожна сторінка має власну canonical-адресу. Перехід між сторінками працює звичайними HTML-посиланнями без бекенда. Зміни карток робіть у файлах статей, оскільки каталог генерується з них.

Для кожної статті зазначайте фактичну дату публікації у JSON-LD: `"datePublished": "2026-09-10"`, у видимому елементі `<time datetime="2026-09-10">10 вересня 2026</time>` та метатезі `article:published_time`. Генератор каталогу бере дату з `datePublished` і показує її українською поруч із часом читання. Дата публікації не змінюється під час повторної генерації каталогу.
